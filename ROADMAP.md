# Roadmap

This roadmap separates the working public MVP from planned product work.

## 0.2 — Public MVP

- [x] Offline buyer scenario and evidence-based evaluation
- [x] Optional Gemini/OpenRouter conversation through Supabase
- [x] Responsive PWA interface and dark mode
- [x] Render Blueprint, health check, CI, and security documentation
- [x] Honest roadmap states for unfinished controls

## 0.3 — Persistence and authoring

- [ ] Supabase Auth and organization onboarding
- [ ] Session/message persistence and training history
- [ ] Product CSV import with validation and preview
- [ ] Product and sales-rule CRUD
- [ ] Scenario builder backed by catalog facts

## 0.4 — Coaching and team workflows

- [ ] Structured AI evaluation and coaching in the interface
- [ ] Team invitations, assignments, and manager dashboard
- [ ] Configurable evaluation rubric and forbidden promises
- [ ] KZ and EN localization
- [ ] Accessibility audit and expanded mobile E2E coverage

## Later

- [ ] Ollama adapter for private deployments
- [ ] WebLLM experiment for supported WebGPU devices
- [ ] CRM/LMS integrations
- [ ] Voice role-play after privacy and cost review

Roadmap items are proposals, not delivery promises. Please discuss large changes in an issue before implementation.
